## 📊 주요 기능 및 특허 구현 상세

본 솔루션은 **AI 시스템 생애주기 중 2단계(데이터)와 3단계(모델)**의 신뢰성 평가에 초점을 맞추고 있습니다. Adult 데이터셋(예: UCI Adult Income)을 사용해 소득 예측 모델의 공정성을 평가하며, 민감 속성(성별, 인종 등)에 따른 편향을 진단하고 완화합니다.

### 1️⃣ 정량적 편향 진단 점수 발급

AI 모델의 예측 결과와 보호 속성(`race`, `gender` 등)을 비교하여 **편향성을 수치화하고 위험 등급으로 분류**합니다. 주요 지표는 다음과 같습니다:

| 지표                            | 설명                                                                 | 공정 기준              |
|-------------------------------|--------------------------------------------------------------------|---------------------|
| **Disparate Impact (DI)**      | 민감 속성 그룹 간 예측 비율의 차이를 측정. 값이 1에 가까울수록 공정.       | 0.8 ≤ DI ≤ 1.2      |
| **Statistical Parity Difference (SPD)** | 민감 속성 그룹 간 예측 확률 차이. 0에 가까울수록 공정.            | -0.1 ≤ SPD ≤ 0.1    |
| **Average Odds Difference (AOD)** | True Positive Rate와 False Positive Rate의 차이를 측정. 0에 가까울수록 공정. | -0.1 ≤ AOD ≤ 0.1    |
| **Equalized Odds Ratio**       | 민감 속성 간 예측 정확도의 일관성을 평가. 1에 가까울수록 공정.            | 0.8 ≤ Ratio ≤ 1.2   |

- **출력**: 편향 지표를 기반으로 한 정량적 점수와 위험 등급(예: 낮음, 중간, 높음).
- **활용**: 모델의 공정성 상태를 직관적으로 파악하고, 편향 완화 전략 수립에 활용.

### 2️⃣ 데이터 및 모델 시각화

- **원본 데이터 시각화**: Pygwalker를 활용해 데이터 분포와 상관관계 시각화.
- **편향 분석 시각화**: 민감 속성별 예측 결과 비교(예: 성별/인종별 소득 예측 분포).
- **전후 비교**: 편향 완화 전후 지표 변화를 시각적으로 제공(예: 막대그래프, 히스토그램).

### 3️⃣ 편향 완화 및 의사결정 지원

- **방법**: Fairlearn의 `ThresholdOptimizer`, `ExponentiatedGradient` 등 활용.
- **결과**: 편향 완화 후 모델 성능과 공정성 지표 개선(예: DI, SPD 감소).
- **가이드라인**: 편향 원인(예: 데이터 불균형, 민감 속성 상관관계)에 따른 개선 권고사항 제공.

### 4️⃣ 특허 기반 워크플로우

- 특허(10-2669206호)에 명시된 AI 생애주기 평가 방법론을 준수:
  - **데이터 단계**: 데이터 품질(DQ) 보고서 생성, 결측치/이상치 처리.
  - **모델 단계**: 모델 성능 및 공정성 평가, 편향 완화 전략 적용.
  - **결과 저장**: JSON 형식으로 편향 분석 결과 저장 및 추적 가능.

## 🔍 제한사항 및 향후 계획
### 제한사항

- 데이터셋 의존성: Adult 데이터셋 외 다른 데이터셋은 추가 전처리 필요.

- 컴퓨팅 자원: 대규모 데이터셋의 경우 모델 튜닝 시간이 길어질 수 있음.

### 향후 계획

- 다양한 데이터셋 지원: 의료, 금융 등 다른 도메인 데이터셋 확장.
- 자동화 강화: 데이터 전처리 및 편향 완화 프로세스 자동화.
- 실시간 대시보드: 웹 기반 인터페이스로 결과 시각화 제공.
- 확장된 공정성 지표: Equal Opportunity Difference, Theil Index 등 추가.
